# AI use disclosure

The Congressional App Challenge requires full disclosure of AI tools.

## Third-party AI in the app

- Speech-to-text: Deepgram or AssemblyAI converts recorded audio into
  words with timestamps. This is the only AI service the app calls.

## AI assistance during development

- Claude (Anthropic) was used as a coding assistant for planning,
  scaffolding, code review and debugging help.
- All metric algorithms, pause detection, UI and backend logic were
  written, tested and understood by the author. Specific examples of
  the author's own problem-solving are in the written submission answers.

Update this file as the project evolves.
